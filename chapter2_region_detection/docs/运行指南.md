# 运行指南（第二章：单区域检测，多区域复用）

本工程实现第二章方法闭环：**LLM先验生成 → 世界模型前瞻评估 → PPO后验选择**，用于**单区域检测**；多区域仅体现为同一套代码在不同 `region_id` 上独立运行（第三章协作层不在此实现）。

---

## 1. 安装与环境

```bash
cd chapter2_region_detection
pip install -r requirements.txt
```

> 建议使用 Python 3.8+；如在 CC4 平台容器中运行，请先确认 `torch` 可用（CPU/GPU 均可）。

---

## 2. 三种运行模式

在 `configs/cc4.yaml` 中设置：

- `mode: mock`：**无需CC4数据**，使用内置模拟环境，保证训练流程能跑通（你当前阶段推荐）
- `mode: replay`：回放从CC4导出的离线日志（jsonl），便于调试/复现实验
- `mode: online`：对接CC4平台实时交互（需要补全 `src/cc4_client.py` 里的 `OnlineCC4Client`）

---

## 3. 快速跑通（无CC4数据）

```bash
python experiments/run_train_posterior.py --region_id 0
```

---

## 4. 推荐流程（更贴论文闭环）

### (1) 采集交互轨迹（训练世界模型的数据）
```bash
python experiments/run_collect_random.py --region_id 0 --steps 3000
```

会生成：
- `data/replays/replay_region0.npz`

### (2) 训练世界模型（Dynamics Ensemble）
```bash
python experiments/run_train_world_model.py --region_id 0
```

会生成：
- `checkpoints/world_model_region0.pt`

### (3) 训练PPO后验选择器（融合LLM先验+世界模型证据）
```bash
python experiments/run_train_posterior.py --region_id 0 --use_trained_world_model
```

会生成：
- `checkpoints/ppo_posterior_region0.pt`

### (4) 部署推理（单区域）
```bash
python experiments/run_deploy_region.py --region_id 0 --steps 200
```

---

## 5. 多区域复用（第二章：各区域独立单区域检测）

```bash
python scripts/run_all_regions.py --regions 0,1,2
```

---

## 6. 输出位置

- 训练轨迹：`data/replays/`
- 模型权重：`checkpoints/`
- 可按需扩展日志：`runs/`
